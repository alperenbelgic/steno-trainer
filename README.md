# Steno Trainer

A browser-based steno practice tool built with React + Vite.

Loads word/stroke pairs from the [Lapwing](https://lapwing.aerick.ca/) dictionary and quizzes you on them. Shows a visual steno keyboard that highlights the correct keys for each stroke.

## Stack

- React
- Vite
- `lapwing-base.json` — source dictionary

## Run locally

```bash
npm install
npm run dev
```
